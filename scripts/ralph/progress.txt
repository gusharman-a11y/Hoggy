## Codebase Patterns
- Next.js 16 (App Router): `next lint` is gone; lint is `eslint .` with flat config eslint.config.mjs (eslint-config-next/core-web-vitals + /typescript). Read node_modules/next/dist/docs/ for API changes.
- `next dev` writes AGENTS.md at repo root; it is committed on purpose (removing it just re-creates it).
- Path alias `@/*` -> `src/*` (tsconfig + vitest.config.ts). Unit tests: `src/**/*.test.ts`. E2E specs: `e2e/`.
- Playwright config starts `next dev -p 3100` (E2E_PORT overrides) and reuses a running server unless CI is set; run with `CI=1 npm run e2e` so it starts and stops its own server.
- Browser check = a Playwright spec that saves a screenshot into scripts/ralph/shots/<ID>-*.png.
- DB: `getDb(file?)` from `@/db` (file > DATABASE_PATH > data/app.db), cached on globalThis; migrations auto-run on open. New schema = new `src/db/migrations/NNN_name.sql` (each applied in its own transaction, recorded in `_migrations`); never edit an applied one. Tests: `getDb(':memory:')` + `closeDb()` in afterEach.
- node:sqlite rows come back as plain objects typed `unknown`-ish: cast `.all() as {..}[]`. Foreign keys are ON (PRAGMA set in openDb).
- Auth: pure helpers in src/lib/users.ts take a `db` (unit-testable); src/lib/auth.ts wraps them with next/headers cookies: getCurrentUser(), requireRole(roles, nextPath) (logged out -> /login?next=..., wrong role -> /?denied=1), logIn(userId)/logOut() for server actions. Cookie `sl_session`. Use safeNext() for any redirect target from user input.
- Server actions live in src/app/*-actions.ts ("use server") with client forms using useActionState. React 19 RESETS the form after an action: return submitted values in state and set defaultValue, or fields go blank on error.
- In Playwright, don't use getByRole("alert") — Next's route announcer is also role=alert. Use locator("p.error").
- Seed: `npm run seed` = tsx scripts/seed.ts -> seed(db) in src/db/seed.ts (idempotent; extend it there). tsx resolves the `@/` alias. Demo: DEMO2026, manager@demo.test & finance@demo.test / password123.
- Build: fs calls on dynamic paths need `/*turbopackIgnore: true*/` inside path args or Turbopack traces the whole project; migrations are shipped via outputFileTracingIncludes in next.config.ts. node:sqlite builds fine under Next 16.
- Conferences: src/lib/conferences.ts searchConferences(filters, db = getDb()) / getConference(slug, db) / conferenceFacets(db) / slugify(); filters q, specialty, country, month (YYYY-MM, overlap), from (YYYY-MM-DD, end_date >= from — use today for "upcoming"). Sample data in src/db/sample-conferences.ts, inserted by seedConferences(db) (INSERT OR IGNORE by slug = slugify(name-year)); tests call seedConferences on :memory:.
- Ingest: src/ingest/extract.ts extractEvents(html, pageUrl) -> ExtractedConference[] (pure, no I/O); src/ingest/upsert.ts upsertConference(c, source, db)/upsertConferences(list, source, db) dedupe by slugify(name)+start_date, COALESCE so blanks never wipe known values, unique slug gets -2/-3 suffix. Fixtures in src/ingest/__fixtures__ (SAMPLE names, example.org only).
- E2E runs against data/app.db (not seeded); make specs self-sufficient (unique emails, create a hospital via signup) until US-024 adds a temp DB.
- Ingest runner: src/ingest/runner.ts runIngest({db, fetch, sleep, now, log}) — all I/O injectable; tests pass a fake fetch + fake clock (see runner.test.ts fakeWeb). addSource/listSources for the `sources` table. CLI: `npm run ingest [-- add URL | list]` (scripts/ingest.ts). robots.txt parsing in src/ingest/robots.ts (pure).
- Pages read URL filters via `searchParams: Promise<Record<string,string|string[]|undefined>>`; normalise in a pure helper (src/lib/conference-query.ts filtersFromParams) so it's unit-testable. Plain `<form method="get">` keeps filters in the URL with no client JS.
- Dates on screen: formatDateRange()/todayIso() in src/lib/format.ts.
- E2E specs needing conferences/demo users: `test.beforeAll(() => execSync("npx tsx scripts/seed.ts"))` (idempotent, seeds data/app.db).
