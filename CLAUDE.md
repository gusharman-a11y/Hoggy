# Hoggy — notes for Claude

Read this first in every session.

## What Hoggy is
Conference-first trip planner for AU/NZ doctors. The conference (or course) is the reason
for the trip and the reason it's claimable. Then: make a trip of it (what's on around it),
package it, and claim only the work portion.

## Owner's preferences (Angus)
- **No over-explaining.** In the app and in replies. Labels, not sentences. No intro
  paragraphs, no narrating the UI, no explaining where data came from beyond a small
  source link. Too much explaining reads as AI-written. See docs/design/voice.md.
- Must not look "AI vibe-coded": avoid Inter/Bricolage/Instrument-type default fonts,
  initials-on-gradient tiles, pill overload, card-everything layouts.
- Replies to the owner: short, plain, phone-friendly. Tables over paragraphs.

## Data rules
Dates only from the organiser's own page, with source URL + quote. Never invent CPD
hours, fees or dates. Never bypass bot blocks. See docs/team/country-desks.md.
