# Voice: labels, not sentences
- Headings 1–4 words. No intro paragraph under a heading unless it says something the screen doesn't (then ≤8 words).
- Never explain what a section is, how it works or where data came from. Provenance is a linked host: `barossavintagefestival.com.au ↗`.
- No narrating the UI ("Tap X to…", "Here you can…"), no reassurance filler, no hedging stacks, no "please", no em-dash asides, no "!", no rhetorical questions.
- Numbers speak: "2,132 conferences · 75 countries", not a paragraph of counts.
- Buttons: verb + object, 1–3 words ("Plan trip", "Add", "Book flights"). Empty states: one line + one action.
- Status chips: "Confirmed", "Re-checking", "Estimate", "Commercial", "During conference", "+2 days after". Dates as dates.
- Honesty stays, as the shortest true label or one footnote line: estimates, "check organiser" for CPD, commercial, work/personal split, "tax rules vary".
- Legal pages keep substance: headings, short bullets, one-line draft note.
- Australian English. No superlatives (tools/copy-lint.js).
