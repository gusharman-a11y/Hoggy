The font files in this folder are subsets of IBM Plex, published by IBM under the SIL Open Font License, Version 1.1
(https://openfontlicense.org). Copyright 2017 IBM Corp. (https://github.com/IBM/plex), with Reserved Font Name "Plex".

- plex-sans-400.woff2: IBM Plex Sans Regular (text).
- plex-sans-600.woff2: IBM Plex Sans SemiBold (text: buttons, labels, bold).
- plex-sans-condensed-700.woff2: IBM Plex Sans Condensed Bold (display: headings, numerals, the wordmark).

How they were made: the Latin files from the Fontsource npm packages (v5.3), cut down with fontTools
(pyftsubset) to Basic Latin, Latin-1 and the punctuation the app uses (dashes, quotes, ellipsis, bullet, euro, arrows),
with only the kern and liga features and no hinting, so all three together weigh about 37 KB. The font names are kept
as published; the copyright and licence entries travel inside each file.
